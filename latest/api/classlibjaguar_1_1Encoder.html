class Encoder

Stateful Jaguar stream builder.

This class is move-only!

Public Functions

Encoder(Writer &&writer)

Create a encoder that will own and maintain a Writer.

Parameters:

writer – The writer to use

Writer &&ReleaseWriter() &&

Release the writer for use outside the encoder.

Note

This function requires you to move from the encoder to prevent further use of this object without a writer, like so: 

Writer myWriter = std::move(myEncoder).ReleaseWriter();

Throws:

std::runtime_error – If the writer object is invalid due to moving

Returns:

The writer

template<typename T>
inline void Write(const Index &index, const T &provider)

Write the provided structure and data to the stream.

Parameters:

  • index – The Index to write

  • provider – The provider to use for acquiring index entry payloads

Throws:

  • std::runtime_error – If any types in the index fail type layout validation

  • std::runtime_error – If the index is invalidly structured (e.g., a ValueEntry with an object type)

  • std::runtime_error – If the provider fails to provide data

class PayloadProvider

Interface for Encoder value requisition.

Note

When implementing this, use exceptions to communicate failure to the encoder.

Public Functions

virtual void String(uint64_t id, std::ostream &out, std::size_t chunkSize, std::size_t offset) = 0

Called to request a string value; may be called multiple times for large strings.

Note

As long as the appopriate methods as given by GetTransferMethod have actual functionality, this method may be left as a stub

Warning

If the requested amount of data is not provided (too much or too little), encoding will halt.

Warning

If the returned data is not proper UTF-8, encoding will halt.

Parameters:

  • id – The ID of the value to fetch, guaranteed to be a value that exists

  • out – The stream to write output to (use write, not operator<< to ensure exact transfer)

  • chunkSize – The requested amount of string data to send (used for large strings); will always be aligned to 4 bytes except for at the end of strings to ensure that all sequences are valid UTF-8

  • offset – Where in the string to start reading from

virtual std::istream *StringViaStream(uint64_t id) = 0

Called to request a string value via stream-stream transfer.

Note

As long as the appopriate methods as given by GetTransferMethod have actual functionality, this method may be left as a stub

Warning

If the stream provides data that is not proper UTF-8, encoding will halt.

Warning

Once a stream pointer is returned via this method, the encoder has exclusive ownership! The stream will be freed when it is no longer needed!

Parameters:

id – The ID of the value to fetch, guaranteed to be a value that exists

Returns:

A pointer to a stream through which the stream may be read

virtual uint64_t Integer(uint64_t id, uint8_t bits, bool isSigned) = 0

Called to request an integer value.

Warning

Parameters:

  • bits – The bit width of the integer being requested (e.g., 32 for a uint32_t), guaranteed to be 8, 16, 32, or 64
